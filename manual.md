## Установка и настройка git'a

Чтобы установить git в Linux нужно выполнить команды:
```bash
sudo apt update
sudo apt install git
```

Чтобы узнать имя текущего пользователя:
```bash
whoami
```

Чтобы узнать имя хоста:
```bash
hostname
```

Чтобы узнать текущую директорию:
```bash
pwd
```
